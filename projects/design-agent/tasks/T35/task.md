2026-08-01 补充导航架构修正：

- 如果当前首页顶部导航和产品功能目录都使用锚点滚动到首页模块，这只是低保真 / 单页演示阶段的效率处理，不符合最终官网信息架构。
- 正式官网应使用多页面导航：首页只做摘要和入口，产品、解决方案、集成、案例、关于、联系等栏目应进入独立页面或页面族。
- 锚点只适合同页详情小目录或同页表单 CTA，不应替代站点级导航。
