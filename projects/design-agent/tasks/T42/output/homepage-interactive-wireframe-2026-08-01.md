# 餐道官网完整首页动态交互低保真原型

## 1. 产物

| 文件 | 说明 |
| --- | --- |
| `homepage-interactive-wireframe.html` | 可打开、可点击、可 hover 的单文件低保真交互原型 |

## 2. 可体验交互

### 首屏 spotlight

- 页面打开后自动在 `订单 / 菜单 / 配送 / 数据` 之间轮播。
- 点击首屏进度点可手动切换聚焦内容。
- 右侧连接图会同步高亮相关节点。

### 经营问题入口

- hover 或点击问题卡片，会切换当前问题说明。
- 下方解决方案和流程步骤会同步更新。
- hover 会出现轻量浮层，展示少量细节。

### 平台能力 Tab

- 点击 `订单与菜单 / 点餐与配送 / 数据与集成`。
- 平台连接图中的节点会随 Tab 切换。

### 产品矩阵

- hover 产品卡会显示简短说明浮层。
- 点击产品卡会显示原型提示，表示这里后续应进入对应详情页。

### 集成与合作伙伴

- 点击不同集成分类，会切换目录预览内容。
- 该区域模拟后续集成目录页的搜索与分类入口。

### 客户案例

- 案例区域支持 3 个案例切换。
- 切换后会更新案例标题、说明、指标和视觉占位。

### 下一步分流

- 点击 `预约示范 / 联系销售 / 合作伙伴 / 客户支持` 会打开表单弹层。
- 提交后显示原型反馈状态。

## 3. 设计边界

- 当前仍是低保真原型，不是最终视觉稿。
- 不接入真实表单、后端、埋点或路由。
- 二级页面入口以提示方式表达，不在本轮展开。
- 所有交互都服务于“官网轻交互”，不做后台式复杂操作。

## 4. 后续建议

如果继续推进，建议下一步补：

- 移动端交互版。
- 首屏 4 个 spotlight 的高保真视觉状态。
