# T43 首页策略诊断

## 结论

用户指出的问题成立。

T43 虽然修正了“顶部导航不应是首页锚点”的结构问题，但过度把首页处理成了页面入口目录，导致首页失去官网最关键的宣传作用。当前效果更像说明书、信息架构样张或路由演示，而不像真正可交互的餐饮科技 SaaS 官网。

## 问题判断

### 1. 不像真正的可交互官网

当前交互主要是页面切换、筛选、表单分流，属于“功能可点”。但真正的官网交互应该帮助用户形成第一感官判断：

- 我是否一眼理解这家公司能做什么。
- 它是否适合我的餐饮品牌规模和场景。
- 它是否足够可信。
- 我是否愿意继续看产品、案例或预约演示。

T43 的交互偏“原型说明”，缺少官网式的视觉节奏、内容吸引、场景推进和即时反馈。

### 2. 首页宣传作用被削弱

首页不是纯入口页。首页应承担官网最重要的第一印象任务：

- 讲清楚餐道的核心价值。
- 呈现企业能力的整体感。
- 用餐饮场景、经营结果和可信证明建立吸引力。
- 给用户一个“这家公司成熟、专业、值得继续看”的判断。

T43 首页虽然有入口分发，但把产品、集成、案例等都压成目录卡片，导致首页缺少情绪、证据、故事和商业说服力。

### 3. 内容结构差的原因

主要原因不是 PRD 本身，而是低保真搭建时的转译问题。

PRD 已经明确要求：

- 首页展示定位、产品矩阵、案例、集成和 CTA。
- 产品详情页使用独立结构。
- 集成目录支持搜索、分类和状态。
- 联系页按意图分流。

但 T43 在修正锚点问题时过度强调“首页只做摘要和入口”，把摘要做得太薄，把首页降级成了站点地图。

PRD 的次要问题是：它偏信息架构和功能需求，缺少更明确的首页宣传验收标准，例如首屏必须体现的品牌气质、视觉冲击、经营结果、客户证明和“为什么选择餐道”的叙事顺序。

## 责任拆分

| 来源 | 占比判断 | 说明 |
| --- | --- | --- |
| 低保真搭建转译问题 | 主要 | 过度纠正锚点问题，把首页从营销首页变成入口目录 |
| PRD 表达问题 | 次要 | PRD 页面清单完整，但首页销售力和第一感官标准不够强 |
| 低保真介质限制 | 较小 | 低保真也可以有清晰宣传节奏，不能把问题归因给低保真本身 |

## 修正方向

下一版不应继续在 T43 上小修小补，而应做“多页面低保真官网 v2”：

- 保留多页面路由。
- 重做首页，让首页成为品牌和能力的第一感官页面。
- 首页内容不做完整说明书，而做经营结果、场景冲突、产品能力、集成可信、案例证明和 CTA 的连续叙事。
- 产品、集成、案例、关于、联系仍然独立承接深内容。

## 首页 v2 应有的内容顺序

```text
首屏品牌定位和经营结果
-> 客户 / 门店 / 订单 / 集成等可信证明
-> 餐饮经营痛点与餐道解决方式
-> 平台能力互动展示
-> 产品矩阵预览
-> 集成生态可信证明
-> 客户案例 / 结果证明
-> 为什么选择餐道
-> 预约示范 / 联系销售 / 合作伙伴分流
```

## 下一步建议

建议创建下一版原型：`T44 - 餐道官网多页面低保真交互原型 v2`。

目标不是增加更多页面，而是重建首页宣传力，并让其他页面继续承接深内容。
