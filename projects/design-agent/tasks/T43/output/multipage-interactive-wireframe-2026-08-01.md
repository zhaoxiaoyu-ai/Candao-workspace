## 2. 本轮修正

T42 的顶部导航是单文件首页原型里的锚点滚动。本轮改为多页面原型：

- 顶部导航切换独立页面视图。
- URL 会模拟成 `?page=products`、`?page=integrations`、`?page=contact` 等页面路由。
- 产品卡进入独立产品详情页，不再滚动到首页模块。
- 首页只做摘要和入口，不承载所有功能详情。

## 4. 可体验交互

- 顶部导航页面切换，不触发首页滚动。
- `产品` 页面点击产品卡进入对应详情页。
- `解决方案` 页面点击场景卡切换方案说明。
- `集成与合作伙伴` 页面支持搜索、分类和状态筛选。
- `客户案例` 页面支持案例标签筛选。
- `资源 / FAQ` 页面支持问题展开与收起。
- `联系我们` 页面按不同意图切换字段。
- 移动端顶部菜单可展开。
- 语言按钮模拟简体 / 繁体切换反馈。

## 5. 验证结果

已完成以下本地验证：

- JS 语法检查通过。

## 6. 后续建议

下一步如果继续深化，可以按这个顺序：

1. 把当前单文件原型拆成真实多 HTML 或前端路由结构。
2. 为每个产品详情页补更完整的低保真内容区块。
3. 做集成目录的详情抽屉和请求新集成表单。
4. 做客户案例详情页模板。
5. 将低保真页面转成 Figma 高保真设计或网页生成 Agent 输入。
