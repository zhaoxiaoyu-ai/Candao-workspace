# PRD：餐道官网新版优化

## 1. 项目概述

餐道官网新版需要从基础公司介绍站升级为面向餐饮品牌、餐饮集团和技术合作伙伴的获客与信任转化站。

新版官网应帮助目标用户快速理解餐道能解决哪些餐饮营运问题、有哪些产品能力、能接入哪些外部系统、有哪些客户案例，并清晰进入预约示范、联系销售、合作伙伴申请或客户支持。

## 2. 项目目标

| 目标 | 说明 |
| --- | --- |
| 建立清晰定位 | 让用户快速理解餐道是餐饮订单、菜单、配送与营运数据平台 |
| 提升线索转化 | 通过明确 CTA 和表单分流提升有效销售线索 |
| 展示产品矩阵 | 将订单、菜单、点餐、配送、数据等能力组织成可理解的产品结构 |
| 建立可信证明 | 通过客户案例、集成能力、公司资料和合规信息降低决策风险 |
| 支持长期运营 | 支持 SEO、案例、FAQ、资源内容和后续市场扩展 |

## 3. 目标用户

| 用户类型 | 主要需求 |
| --- | --- |
| 连锁餐饮营运负责人 | 统一管理多平台订单、门店资料、菜单、配送和营运数据 |
| 餐饮集团 IT / 数字化负责人 | 评估系统集成、数据安全、稳定性和实施成本 |
| 餐饮品牌市场 / 业务负责人 | 了解自有点餐、会员、营销和客户增长能力 |
| 餐饮品牌出海 / 入港负责人 | 快速评估本地平台、实施服务和交付可行性 |
| POS、支付、配送、CRM 等技术合作伙伴 | 寻找集成、渠道和商业合作入口 |
| 现有客户 | 获取支持、查看常见问题和联系服务团队 |

## 4. 问题定义

当前官网需要重点解决以下问题：

| 问题 | 影响 |
| --- | --- |
| 产品结构不够清晰 | 用户难以理解餐道的能力边界和适用场景 |
| 内容偏介绍型 | 不能充分回答客户决策过程中的问题 |
| 缺少强转化路径 | 不同意图的用户都进入同一联系入口，线索质量难提升 |
| 集成能力展示不足 | 用户无法快速判断餐道是否能接入现有系统 |
| 案例与信任材料不完整 | 难以形成企业级采购信心 |
| 合规和服务信息不集中 | 国际 / 本地客户在评估时缺少必要信任依据 |

## 5. 官网定位

推荐定位：

> 面向餐饮品牌的全渠道订单、菜单、配送与营运数据平台。

产品表达应围绕餐饮经营结果展开，而不是只陈列系统功能。核心价值包括：

- 统一管理多平台订单。
- 一次维护菜单、库存和门店资料。
- 支持自有点餐渠道和会员营销。
- 编排自有骑手与第三方配送能力。
- 整合订单、渠道、配送、财务和营运数据。
- 接入餐饮品牌已有系统和合作生态。

## 6. 成功指标

| 指标 | 建议目标 |
| --- | --- |
| 预约示范 / 联系销售表单提交量 | 上线后 90 天建立基准，并持续优化 |
| 有效线索率 | 表单关键信息完整率不低于 80% |
| 核心 CTA 点击率 | 首页和产品页主 CTA 点击率不低于 5% |
| 集成页互动率 | 搜索、筛选或请求集成互动率不低于 20% |
| 案例页阅读深度 | 50% 滚动深度用户占比不低于 40% |
| SEO 基础健康 | sitemap、metadata、hreflang、canonical、结构化数据配置完整 |

## 9. 内容策略

| 内容原则 | 要求 |
| --- | --- |
| 先讲业务结果 | 避免只堆功能名，先说明能改善什么 |
| 术语统一 | 产品名、能力名、CTA 和页面标题保持一致 |

| 内容可扩展 | 产品、集成、案例、FAQ 应支持持续更新 |

## 14. 验收标准

| 需求 | 验收标准 |
| --- | --- |
| 首页 | 首屏清晰展示定位、核心价值和主 CTA |
| 首页 | 页面中包含产品矩阵、集成预览、案例预览和底部转化 |
| 产品页 | 核心产品详情页结构一致，包含痛点、收益、功能、集成、案例和 CTA |
| 集成页 | 至少支持 5 类集成分类，并显示支持状态 |
| 集成页 | 用户可以搜索或筛选集成项 |
| 案例页 | 至少上线 2 个授权案例或可用匿名案例 |
| 联系页 | 至少包含预约示范、联系销售、合作伙伴、请求集成、客户支持入口 |
| 合规 | 隐私、条款、Cookie、数据安全入口可访问 |
| SEO | sitemap、metadata、canonical、hreflang 配置完整 |
| Analytics | CTA、表单、搜索、语言切换事件可追踪 |
| 响应式 | 移动端无文本溢出、按钮重叠或表单不可用问题 |

## 15. 风险与依赖

| 风险 / 依赖 | 影响 | 处理方式 |
| --- | --- | --- |
| 产品命名未统一 | 影响导航和页面文案 | 产品、销售、市场共同确认 |
| 集成状态未确认 | 影响集成页可信度 | 建立集成清单和状态字段 |
| 客户案例授权不足 | 影响信任证明 | 优先推进授权，同时准备匿名案例 |
| 规模数据口径不一致 | 影响品牌可信度 | 建立官网可用数字清单 |
| 表单接收和响应流程未定 | 影响线索转化 | 上线前确认接收人和响应机制 |
| 合规资料缺失 | 影响上线 | 隐私、条款、Cookie、数据处理说明列为 P0 |
| 内容审核不足 | 影响专业度 | 由业务、产品、市场和法务共同审核 |
