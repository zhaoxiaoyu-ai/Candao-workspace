## 竞品共性

这三个竞品都不是纯“软件工具官网”，而是在讲“餐饮经营结果”。页面核心不是功能堆叠，而是把餐厅现场、订单效率、集成能力、利润增长、客户体验放在一起讲。

共性可以归纳为：

- 首屏必须快速传达餐饮场景，而不是抽象 SaaS 背景。
- CTA 必须明显，常见方向是预约演示、开始了解、查看价格或获取方案。
- 信任证明很重：客户品牌、餐厅数量、集成伙伴、运营结果都被放在核心路径中。
- 视觉上偏“真实餐厅 + 产品能力”，而不是纯插画或纯后台截图。
- 交互上偏“先被吸引，再理解能力，最后转化”，不是一上来进入复杂功能配置。

## 视觉分析

### Aigens

Aigens 的视觉重点是“硬件产品 + 餐厅现场 + 企业可信”。首屏是深色遮罩下的餐厅/自助点餐机真实场景，左侧大标题用白色和亮绿色形成强对比，底部直接压一排品牌 logo，顶部导航是半透明圆角胶囊。

可借鉴：

- 用真实餐厅场景图承载首屏，不要用泛科技渐变。
- 产品设备或点餐 UI 要在首屏可见，帮助用户立刻理解这是餐饮科技。
- 亮色关键词可以只点亮一句核心收益，例如增长、效率、体验。
- 客户 logo 可以贴近首屏底部，作为第一屏信任锚点。

不要照搬：

- Aigens logo、客户 logo 原图、点餐机画面、首屏文案原句、品牌绿色比例。

### Deliverect

Deliverect 的页面是集成目录型，视觉更功能化。移动端可见高对比黑白 logo、超粗 uppercase 标题、绿色 CTA、集成卡片和搜索/目录结构。它的优势不是沉浸式情绪，而是“我有很多连接能力，你可以搜索和找到对应工具”。

可借鉴：

- 集成/伙伴模块适合做成清晰目录：搜索框、分类、卡片、合作伙伴 logo。
- 标题可以用高字重、短句、强秩序感，适合表达“平台能力很完整”。
- 绿色按钮和集成卡片可以作为功能区的行动信号。

不要照搬：

- Deliverect logo、集成伙伴 logo 原图、页面原文、具体卡片图形。

### TabSquare

TabSquare 是三者里视觉叙事最强的参考。首屏使用完整餐厅用餐场景摄影，暖色灯光、深色遮罩、橙色按钮、带情绪的 serif 标题，整体更像“高端餐饮体验 + 技术在背后编排”。移动端也保持沉浸式摄影，标题和 CTA 顺序清晰。

可借鉴：

- 首屏可以用全屏真实餐厅场景，给官网更强气质。
- 标题可以带一点情绪感，不只讲“提升效率”，还讲“创造更好的用餐体验”。
- 主 CTA 用暖橙色，次 CTA 用半透明描边，形成清楚层级。
- 移动端首屏可以先给图像情绪，再露出标题和 CTA，形成自然下滑动力。

不要照搬：

- TabSquare logo、照片、人物形象、原文、按钮文案、独特品牌橙色使用比例。

## 推荐视觉融合方向

主参考取三者共性：真实餐饮场景、餐饮经营结果、明确转化入口、客户/集成证明。

融合方式：

- 从 TabSquare 借鉴首屏气质：大幅真实餐厅摄影、暖光、深色遮罩、强情绪标题。
- 从 Aigens 借鉴产品明确性：在首屏或第二屏露出真实产品界面/设备/工作流，不让页面只像餐饮品牌广告。
- 从 Deliverect 借鉴结构清晰度：集成和伙伴能力用搜索、分类、卡片表达，避免藏在长段文案里。

推荐视觉关键词：

```text
真实餐饮现场、温暖但专业、科技隐藏在体验背后、企业可信、清晰转化、平台能力完整
```

建议色彩：

- 背景：深炭黑、暖灰、白色内容区交替。
- 主 CTA：暖橙色，表达餐饮热度和行动感。
- 辅助强调：少量鲜绿色或蓝色，用于增长、效率、系统连接等关键词。
- 避免整站只剩棕橙暖色，需要用白色、黑色和冷色辅助维持 SaaS 专业感。

建议字体：

- 首屏标题可使用有个性的 display serif 或高质量衬线体，增强餐饮体验感。
- 产品能力、卡片、表单、导航用清晰 sans-serif，保持 SaaS 可读性。
- 标题层级要大且果断，正文短行宽，避免营销长段堆积。

## 交互分析

### 导航

三者都将导航设计成“探索型入口 + 明确转化入口”。

- Aigens：产品、集成、解决方案、资源、语言、预约演示。
- Deliverect：解决方案、集成、资源、登录、开始。
- TabSquare：桌面和移动端都强调 Explore，右侧菜单简化。

建议：

- 桌面顶部使用透明或半透明导航，首屏叠在大图上。
- 右侧保留一个高优先级 CTA，例如“预约演示”。
- 移动端保留 logo、Explore/菜单和简洁汉堡按钮，不要把所有导航项直接塞首屏。

### CTA

CTA 需要双层：

- 主 CTA：预约演示 / 获取方案 / 开始了解。
- 次 CTA：查看价格 / 探索产品 / 查看集成。

建议首屏使用一个强按钮加一个弱按钮。强按钮用实色，弱按钮用半透明描边或文字按钮。进入后续模块后重复出现主 CTA，但不要每个区块都强推，避免压迫感。

### 滚动节奏

推荐页面节奏：

1. 首屏：真实餐饮场景 + 一句话定位 + 双 CTA。
2. 立即给信任证明：客户数量、品牌 logo、门店/交易/集成规模。
3. 体验叙事：顾客从发现餐厅、点餐、支付到复购的旅程。
4. 平台能力：模块化展示点餐、支付、会员、集成、运营。
5. 集成预览：搜索/分类/卡片式展示生态能力。
6. 结尾转化：预约演示表单或咨询入口。

### 交互组件

推荐使用：

- 顶部透明导航 + 滚动后变为实底导航。
- 首屏双 CTA。
- 客户 logo 横向滑动或静态网格。
- 旅程叙事 slider，用于展示顾客体验链路。
- 集成模块搜索框 + 分类 chip + 卡片列表。
- 表单 CTA，字段要少，先收集关键意向。

不要优先使用：

- 太复杂的后台式筛选器作为首屏。
- 抽象动效或漂浮图形作为主要视觉。
- 大段功能介绍直接堆在首屏下方。

## 不应照搬

- 不复制三家竞品 logo。
- 不使用竞品原图、视频、人物照片、产品截图。
- 不复写竞品标题、CTA、案例文案。
- 不复刻某个页面的完整布局和区块顺序。
- 不把竞品客户 logo 作为我们的客户证明。

## 简短术语解释

- CTA：行动入口，例如“预约演示”“查看价格”。
- token：设计变量，例如颜色、字号、间距、圆角。
- style-fit：风格贴合度，用来判断生成页面是否贴近参考气质。
- 合规：只学习抽象设计规律，不复制受保护资产。
