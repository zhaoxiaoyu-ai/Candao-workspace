Tappo Pulse / Image2 Direction

TAPPO 微官网视觉升级方向样张

用于指导 Lovable 后续通过 Image2 重做顶部轮播图、入口图标和卡片质感。样张表达方向和可用资产候选；生产使用时仍需避免把可读文字、假 logo、水印直接烧进图片。

需要保留的范围

  • 首页保留点餐/电子菜单入口和订座预约入口。
  • 菜单入口保留，但菜单内容页暂不做；只允许轻量空状态或提示。
  • 订座预约必须保留，并继续支持预约表单、校验、成功弹窗和离开确认。

参考图提炼

  • 顶部轮播图需要广告大片质感、真实材质、光影、景深和食物细节。
  • UI 卡片应有半透明材质、柔和阴影和足够留白，不只是一张白卡。
  • 图标可以是小型 Image2 图形资产，不要只用单一线性图标。
  • 样式需要适配任意主题色，因此色彩应通过 token 注入，图片避免强绑定单一色值。

验收重点

  • 首页视觉第一屏必须更像餐饮品牌广告，而不是普通餐厅照片列表。
  • 点餐入口存在但不展示菜品分类、菜名、价格、购物车或下单 CTA。
  • 订座入口进入可用的 `/booking` 表单。
  • 图片和图标不出现假 logo、乱码文字、水印或不可控品牌文案。

图标落地规则

  • 入口图标可从这张方向稿拆分重绘，或在 Lovable 内用 Image2 分别生成单独小资产。
  • 同屏保持统一光源、统一材质厚度和统一圆角；不要混用摄影图、线框图和扁平插画。
  • 图标 badge 使用主题主色和透明度 token，物件主体保持中性，确保换主题色也成立。

轮播落地规则

  • 首屏图片建议以 40%-50% 页面高度呈现，叠加轻量品牌信息和轮播控件。
  • 图片不承担文案，不烧入品牌名；文案由页面组件叠加并跟随主题样式。
  • 不同主题色只调整 UI token，不强制重染图片，保持食品广告图的通用高级感。
