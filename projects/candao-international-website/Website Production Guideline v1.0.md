# Website Production Guideline v1.0

规范正文位置：

`projects/candao-international-website/tasks/Fix-00/output/Website Production Guideline v1.0.md`

本项目级入口文件用于让后续 Candao International Website 工作在进入具体任务文件前，先发现并读取生产总规则。

本规则是后续 Agent、Skill、Prompt、Figma、Stitch、Image2、AI Web Generator、Prototype、Review 和实现任务的最高优先级规则。

当本规则与 AI 生成结果、原型控制、临时 Prompt、视觉探索或下游任务产物冲突时，以本规则为准。

## 不可变规则

- T05 Sitemap 是唯一有效 IA 来源。
- 官网视觉稿默认使用繁體中文。
- English 必须作为独立 Locale 版本生成。
- 产品能力页必须保留在 Platform 下。
- Order Management 和 Delivery Management 不得提升为一级导航。
- Home 负责品牌认知和转化，不是产品目录页。
- Stitch 和 AI Website Generator 输出默认只是探索产物，不是已批准参考案例。
- A = Design Production，B = Art Direction Review，C = Web Prototype Exploration。

## 后续任务必读

继续任何 T05-T11.5 或后续官网生产任务前，必须读取：

1. 本文件。
2. `projects/candao-international-website/tasks/Fix-00/output/Website Production Guideline v1.0.md`
3. 相关任务目录下的 `production-rule-addendum-v1.0.md`，如果存在。
