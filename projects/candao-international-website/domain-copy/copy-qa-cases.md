# 餐道行业文案 QA 用例

版本：v1.0  
日期：2026-08-15

## 用例字段

每个页面任务至少定义：

- 任务 ID；
- 组件类型；
- 目标角色；
- 页面任务；
- 必须出现的信息；
- 禁止出现的表达；
- 术语要求；
- 失败条件。

## 1. 指标卡

- 目标角色：决策者
- 页面任务：证明规模与可信
- 必须出现：指标名称、数值、来源、适用对象
- 禁止出现：未定义数字、SLA 承诺、泛化价值词
- 术语要求：使用 `品牌数量`、`每日处理订单`、`门店数量` 等已定义指标
- 失败条件：使用不在 `allowed_metrics` 中的数字

## 2. 经营概览

- 目标角色：总部运营
- 页面任务：说明当前营运状态
- 必须出现：渠道、门店、订单状态、异常、下一步操作
- 禁止出现：只写“运营表现良好”
- 术语要求：OMS、CDBI、財務對賬
- 失败条件：删除订单状态或异常条件

## 3. 订单列表

- 目标角色：门店经理 / 总部运营
- 页面任务：处理多渠道订单
- 必须出现：订单编号、渠道、门店、订单状态、配送状态、异常类型、下一步操作
- 禁止出现：无定义字段
- 术语要求：OMS、Order Processing Center
- 失败条件：把多平台订单改成泛称“任务”

## 4. 异常提醒

- 目标角色：门店经理 / 配送主管
- 页面任务：处理异常
- 必须出现：异常对象、触发条件、影响、下一步操作
- 禁止出现：仅写“系统异常”
- 术语要求：接单超时、配送超时、退款未处理、门店状态异常
- 失败条件：缺少下一步操作

## 5. 表单说明

- 目标角色：采购方 / 销售
- 页面任务：分流 Demo
- 必须出现：品牌、地区、门店规模、当前系统、需要解决的问题、提交后安排
- 禁止出现：只写“我们会联系你”
- 术语要求：OMS、DMS、iDMS、CDBI
- 失败条件：字段与演示分流无关

## 6. 操作确认

- 目标角色：运营 / 配送主管
- 页面任务：确认高影响操作
- 必须出现：操作对象、动作、后果、可追踪记录
- 禁止出现：只写“是否继续”
- 术语要求：转派第三方配送、配送状态、派单记录
- 失败条件：不说明状态变化

## 7. 空状态

- 目标角色：门店经理 / 财务
- 页面任务：解释没有数据
- 必须出现：当前对象、没有数据的条件、未来出现条件、下一步
- 禁止出现：仅写“暂无数据”
- 术语要求：异常订单、对账差异、售罄同步
- 失败条件：没有业务对象

## 8. 数据大屏

- 目标角色：管理层 / 总部运营
- 页面任务：看经营趋势和异常
- 必须出现：订单量、渠道、门店、时间范围、异常或对账差异
- 禁止出现：无定义指数
- 术语要求：CDBI、Data Asset、財務對賬
- 失败条件：图表标题没有统计对象和时间范围

## 9. 用户端进度提示

- 目标角色：顾客
- 页面任务：说明订单 / 配送进度
- 必须出现：当前状态、预计下一步、异常时处理方式
- 禁止出现：后台术语堆砌
- 术语要求：已接单、制作中、配送中、已送达
- 失败条件：状态与下一步不一致

## 10. 管理后台页面

- 目标角色：IT / 总部运营
- 页面任务：配置系统和接入
- 必须出现：系统类型、接口对象、数据流、权限、异常处理
- 禁止出现：无缝集成、所有系统均可接入
- 术语要求：AMS / Connector、API、POS、KDS、CRM、ERP
- 失败条件：创造未确认接入承诺

## 11. 产品名大小写敏感

- 目标角色：IT / 配送主管 / 销售
- 页面任务：展示产品能力或技术接入
- 必须出现：`iDMS`、`SaaS` 等标准写法
- 禁止出现：`IDMS`、`Idms`、`idms`、`iDms`、`IdMS`、`SAAS`、`Saas`、`saas`
- 术语要求：必须按 `glossary.yaml` 的 `case_sensitive_terms` 输出
- 失败条件：文案层或样式层把大小写敏感产品名统一成全大写、全小写或首字母大写

## 硬性失败规则

以下情况直接失败：

- 改变业务含义；
- 擅自改变标准术语；
- 使用未定义指标；
- 删除关键条件；
- 将真实内容替换为占位符；
- 使用禁止表达；
- 中文 / 繁體中文默认品牌显示中使用 `Candao`、`candao` 或 `Can Dao`，而不是「餐道」；
- 原型构建 Agent 擅自改写已锁定内容；
- 样式层通过强制大写、小写或自动转换，把 `iDMS`、`SaaS`、`AMS / Connector`、客户名或产品名显示成错误术语。
- 中文 / 繁體中文官网可见文案、Figma、Stitch、React 或截图式界面直接展示 `Finance Center`，而不是「财务对账 / 財務對賬」。
