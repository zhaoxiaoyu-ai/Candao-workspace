# Project: 餐道国际官网重构

## Goal

重构餐道国际官网的策略、信息架构、官网文案、UX、视觉方向、审核机制与最终设计蓝图。

确保项目内所有内部执行文档默认使用简体中文，官网实际展示文案统一输出繁体中文 + 英文双语版本。

## Scope

In scope:

- 餐道国际官网资料整理与输入文档沉淀。
- 官网策略分析、品牌定位、信息架构、Sitemap、官网 Copy、UX 规格、视觉方向、审核报告与最终整合蓝图。
- 多 Agent 执行前置条件、输出语言规范、任务产物格式管理。

Out of scope:

- 官网正式开发上线、部署、CMS 接入、数据埋点，除非后续任务明确纳入。
- 餐道国内官网、产品 App、后台系统或非国际官网相关工作。
- 与非餐道 workspace 或 `ai-workspace` 的资料耦合。

## Source Root

- `projects/candao-international-website/source/`

当前为占位 source root；后续如创建官网原型、前端工程或素材库，统一放入此目录或在任务中明确路径。
