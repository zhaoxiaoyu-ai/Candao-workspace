# Task T03: 官网策略文档

## Goal

基于 T01 输入资料和 T02 v1.1 策略分析结果，完成 Candao 国际官网战略决策固化，形成可直接支撑信息架构、内容生成、UX 和视觉设计的官网战略文档。

本任务重点不是重新分析资料，而是做战略取舍和冻结。

## Output

《Candao International Website Strategy V1.0》

## 输出语言

简体中文；涉及关键品牌定位时增加英文定位版本。

## Required Positioning Format

```markdown
中文定位：

全球餐饮智能运营 SaaS 平台

English Positioning:

Intelligent SaaS Platform for Global Restaurant Operations
```

## Requirements

- 基于 T02 输出，明确品牌定位、目标用户、核心价值主张、信息优先级、页面角色与转化路径。
- 将 T02 的策略判断转化为官网建设原则和决策，不重新做资料整理。
- 可包含英文品牌定位或英文页面命名建议，但解释部分保持简体中文。
- 必须读取 T02 v1.1 的以下章节：
  - `9. 官网内容策略原则`
  - `10. 用户-页面映射关系`
  - `11. 产品体系官网表达层级`
  - `12. 战略决策矩阵`

## Required Output Structure

### 1. 最终品牌定位

必须包含：

- 中文定位；
- English Positioning；
- 定位解释；
- 不采用的定位方向及原因。

### 2. 官网核心叙事

必须明确：

- 首页讲什么；
- 用户第一眼应该理解什么；
- Candao 与竞品/传统系统供应商的差异；
- 不应该讲什么。

### 3. 导航策略

必须确定以下关系：

- Solutions；
- Products / Platform；
- Integrations；
- Resources；
- About；
- Contact / Demo。

### 4. 首页框架

必须确定首页 Section 顺序，例如：

- Hero；
- Trust Bar；
- Problem Switcher；
- Capability Overview；
- Solutions Preview；
- Integrations Snapshot；
- Case Highlight；
- Final CTA。

### 5. 页面优先级

必须区分：

- Phase 1 页面；
- Phase 2 页面；
- 暂不进入官网或仅页脚承接的页面。

### 6. 内容原则

必须指导后续 T06/T07 Copy Agent：

- 从业务结果开始；
- 从客户场景开始；
- 从信任建立开始；
- 每个核心页面必须包含用户问题、解决方案、产品能力、证明材料和 CTA。

### 7. 待确认事项处理策略

必须说明：

- 哪些不阻塞 T03；
- 哪些必须在 T06/T07 前确认；
- 未确认客户、Logo、数据、集成、认证如何在战略文档中处理。

## Acceptance

- 文档可直接传递给 T04 信息架构 Agent。
- 关键定位同时包含中文定位与 English Positioning。
- 文档能阻止后续任务重新发散分析，明确哪些战略已经冻结。
- 不生成最终官网页面 Copy。
