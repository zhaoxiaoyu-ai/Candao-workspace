# Task T04: 信息架构 Agent

## Goal

运行信息架构 Agent，将 T03 已冻结的官网战略转化为国际官网信息架构、页面关系和用户路径。

T04 的角色不是重新判断 Candao 官网应该是什么，而是把已经确定的战略落成可执行的网站结构。

## Output

《Website Information Architecture》

## 前置输入

必须读取：

1. `tasks/T03/output/candao-international-website-strategy-v1.0-2026-08-02.md`
2. `tasks/T02/output/website-strategy-analysis-2026-08-02.md`
3. `tasks/T01/output/candao-international-website-input-document-2026-08-02.md`

优先依据：

- T03 的定位冻结；
- T03 的导航策略；
- T03 的首页内容逻辑；
- T03 的 Products / Platform 与 Solutions 分层；
- T03 v1.1 的品牌语气、视觉原则、页面设计优先级和产品展示体验原则。

## 输出语言

简体中文。

## Example Format

```markdown
首页 Home

目标：
建立品牌认知

主要内容：
Hero、解决方案、产品能力
```

## Requirements

- 基于 T03 官网战略，设计页面体系、导航逻辑、页面关系、用户路径、页面目标和内容层级。
- 必须将战略转化为清晰 IA，不重新做品牌分析、竞品分析或定位判断。
- 必须输出一级导航、二级页面、页面目标、用户入口、内容模块和页面之间的关系。
- 必须区分 Phase 1 与 Phase 2 页面。
- 必须给出 T05 Sitemap 可直接使用的页面结构输入。
- 必须遵守：Home 是品牌与转化入口；Solutions 讲场景；Products / Platform 讲能力；Integrations 是一级战略入口；Contact / Book a Demo 是转化闭环；Resources 第一阶段低承诺。
- 页面中文名称使用简体中文，英文页面名称保留英文。
- 组件、模块或导航字段可保留英文，例如 Hero、Solutions、Products。
- 未确认客户 Logo、规模数据、认证、集成状态、Pricing 和案例，只能做结构预留，不能写成确定内容。

## 禁止事项

- 禁止重新判断官网定位。
- 禁止回到 Excel 原始菜单直接搬运。
- 禁止重新展开品牌策略分析。
- 禁止生成最终官网 Copy。
- 禁止输出简体中文正式网页文案。

## Acceptance

- 信息架构能直接支撑 T05 Sitemap。
- 输出包含页面关系和至少三类核心用户路径。
- 输出能指导 T06 Copy、T08 UX 和 T10 视觉设计继续执行。
- 输出语言保持简体中文，英文仅用于页面名、模块名或官网字段。
