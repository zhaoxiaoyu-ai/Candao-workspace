## High Fidelity Locale Lock

T11 高保真设计必须模拟真实官网，不得把内部分析语言混入官网展示文案。

规则：

- 默认 Figma 和高保真官网 Mockup 使用繁體中文作为可见网站 Locale。
- English 必须作为独立 Locale 版本生成。
- 高保真页面必须保留 T05 导航和产品能力页层级。
- Home 必须先建立品牌级第一印象和转化路径，再展开产品解释。
- 产品能力页必须遵守 `Business Problem -> Solution -> Workflow -> UI Demo -> Business Result -> CTA`。
- 如果视觉稿看起来像内部结构图、产品说明书或结构 Demo，不得验收。
