# Task T11: 高保真视觉方案设计

## Goal

基于 T07 Final Copy、T08 UX Specification、T09 Prototype Validation 和 T10 Website Visual Direction，形成可进入审核与最终整合的官网高保真视觉方案。

T11 不重新探索视觉方向，不重写官网 Copy，不重新做 UX。T11 的重点是用具体视觉方案验证前面策略是否成立，尤其重点验证 Home、Products / Platform、Order Management 和 Delivery Management。

## Output

官网高保真视觉方案。

## 输出语言

简体中文；视觉素材描述可使用中文 + 英文关键词。

## Example Format

```markdown
图片方向：

商业摄影：
Global Restaurant Operation Scene

视频：

Restaurant Operation Workflow Video
```

## Requirements

- 必须读取：
  - `tasks/T07/output/final-website-copy-v1.0-2026-08-03.md`
  - `tasks/T08/output/website-ux-specification-2026-08-03.md`
  - `tasks/T09/output/website-prototype-validation-2026-08-03.md`
  - `tasks/T09/output/t09-v1.1-prototype-validation-supplement-note-2026-08-03.md`
  - `tasks/T10/output/website-visual-direction-2026-08-03.md`
  - `tasks/T10/output/t10-v1.1-visual-direction-supplement-note-2026-08-03.md`
- 必须继承 T10 的 `Operational Clarity for Global Restaurant SaaS`，不重新定义视觉概念。
- 必须继承 T10 v1.1 的：
  - Reference Mapping；
  - Hero Composition Rule；
  - Brand Color Adaptation Process；
  - Page Output Requirement；
  - Visual Review Checklist。
- 明确图片、视频、产品 UI、图标、动效、色彩、字体、版式和页面视觉层级。
- 视觉素材描述可以包含英文关键词，方便检索和生成素材。
- 不生成最终官网 Copy；如引用 Copy，应使用 T07 的繁中 + 英文版本。
- 不为所有页面生成完整 High-fi。
- 不进入 L4 Product Simulation。
- 不使用未确认客户、Logo、数据、认证、集成状态或 SLA。

## Output Structure

必须输出：

1. `Home High Fidelity Design`
   - Hero 视觉；
   - Video / Image Direction；
   - UI Overlay；
   - Product Showcase；
   - Trust fallback；
   - Final CTA。
2. `Platform High Fidelity Key Sections`
   - Capability Map；
   - Platform UI Demo；
   - Product Entry；
   - CTA。
3. `Product Motion Storyboard`
   - Order Management 4-step UI Demo；
   - Delivery Management 4-step UI Demo。
4. `Contact / Book a Demo Visual`
   - Intent Selection；
   - Lead Qualification；
   - Form States；
   - Submit Feedback。
5. `Design System Draft`
   - Tokens；
   - Components；
   - States；
   - Responsive rules。
6. `Asset Plan`
   - Photography；
   - Video；
   - Product UI；
   - Icons；
   - Motion assets。
7. `Figma Handoff Structure`
   - Desktop 1440；
   - Mobile 390；
   - Components；
   - Motion Storyboards；
   - Review Notes。
8. `Visual Review Result`
   - 按 T10 v1.1 Visual Review Checklist 输出检查结论。

## Acceptance

- 视觉方案可进入 T12 审核和 T13 最终整合。
- 输出语言保持简体中文，英文关键词服务于设计执行。
- Home、Products / Platform、Order Management、Delivery Management 的视觉验证重点清晰。
- 已明确哪些页面做完整 High-fi，哪些页面只做模板化方案。
- 已明确品牌色适配流程，而不是自行重建无依据色彩体系。
