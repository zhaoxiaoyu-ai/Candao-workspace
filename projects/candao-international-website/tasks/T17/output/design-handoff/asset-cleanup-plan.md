# 素材清理计划

日期：2026-08-16

## 产品截图

1. 收集 OMS、Menu Center、Store Abnormity Management、DMS、iDMS、CDBI、財務對賬、AMS / Connector 的真实截图。
2. 去除客户名称、订单编号、电话号码、地址、金额、账号、权限和任何敏感数据。
3. 统一裁切为 16:10 或 4:3。
4. 截图不叠加网页光影；外框、阴影和标注层由前端或设计系统提供。
5. 为每张截图记录来源、产品、页面用途、公开范围和清理人。

## 客户 Logo 与案例素材

1. 将 Pizza-Box、JIA Group、Jardine Group、KFC、Pizza Hut、PHD 等授权客户 Logo 归档到独立目录。
2. 记录每个 Logo 是否可用于 Home、Customers、高保真、正式官网。
3. 客户案例图片需记录来源、拍摄主体、公开范围和是否含敏感信息。

## 视频

1. 从旧官网或内部资料中整理 OMS、Menu / Store、DMS / iDMS、CDBI / 財務對賬视频文件。
2. 记录语言版本、封面、时长、字幕和公开范围。
3. 若视频中出现真实客户信息，先清理或替换后再进入官网。
