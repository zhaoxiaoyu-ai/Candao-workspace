# 视觉方向

日期：2026-08-16

## 判断

当前需要重构到“设计输入层”，不是推翻业务内容，也不是把 T25 HTML 直接套深色高保真样式。

T25 的价值在于已经回答了用户对低保真的核心问题：Home 要讲全链路和权威性，Complexity Map 要抽象生态复杂度，Platform 要从产品说明书转成产品如何工作。下一步要解决的是交付方式：把内部证据、访客内容、交互状态、素材缺口和设计语法拆开。

## 设计北极星

餐道国际官网应是“企业级餐饮 O2O 营运科技官网”：

- 真实餐饮行业温度；
- 企业软件的精确感；
- 可追溯的产品截图；
- 清晰的数据连接关系；
- 克制但有目的的动效；
- 面向销售转化对象和品牌决策者的可信叙事。

## 固定规则

- 主色：`#528dff`。
- 深色文字：`#16233d`，按 95% / 65% / 45% 表达层级。
- 页面容器：1440px。
- 实际内容：1200px。
- 圆角：8px 和 16px。
- 中文 / 繁體中文默认品牌显示：餐道。
- 产品名大小写：保留 `iDMS`、`SaaS` 等标准写法。

## 页面差异化语法

| 页面 | 主语法 | 设计目的 |
|---|---|---|
| Home | 电影感 Hero + 产品截图舞台 + 3D 连接中枢 | 建立行业认知和可信度 |
| Solutions | Sticky Scroll 场景叙事 | 让访客从问题进入场景 |
| Platform | 真实产品截图切换器 | 展示产品如何工作 |
| Integrations | 交互式系统网络与 API 数据流 | 验证接入对象和数据方向 |
| Customers | 编辑式案例轮播和行业筛选 | 证明落地和前后对比 |
| Resources | 内容分类、FAQ 和支持路径 | 降低评估和导入疑问 |
| About | 公司时间线、服务体系和地点地图 | 建立长期合作可信度 |
| Demo | 多步骤表单和动态需求摘要 | 完成销售和支持分流 |

## 禁止

- 用通用 SaaS 价值词替代业务对象。
- 用假数据、假 Logo、假新闻、假产品 UI 填充视觉。
- 把每页都做成深色发光卡片。
- 用一套 Grid 平铺全部内容。
- 在访客页面显示内部编号、来源页码、警告、待确认说明。
