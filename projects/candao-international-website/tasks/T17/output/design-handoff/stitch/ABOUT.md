# ABOUT Prompt

## 页面目标

建立公司可信度：说明餐道的公司背景、产品演进、服务交付、质量保障和办公地点。

## 访客可见内容

标题：專注餐飲與零售 O2O 營運系統的產品與服務團隊。  
说明：關於餐道頁說明公司背景、產品演進、服務交付、品質保障、辦公地點和聯絡方式，建立長期合作可信度。

## 模块顺序

1. A01 公司 Hero。
2. A02 公司时间线。
3. A03 产品演进。
4. A04 服务交付体系。
5. A05 安全与认证。
6. A06 办公地点和联系方式。
7. A07 CTA。

## 模块呈现方式

- A01：公司 Hero，使用真实公司 / 团队 / 运营场景图片，缺失时保留素材位。
- A02：公司时间线，桌面横向或分段进度，移动端纵向。
- A03：产品演进序列，OMS、CDBI、DMS、AMS / Connector 逐步展开。
- A04：服务交付体系，产品平台、数据分析、配送履约、质量保障分支。
- A05：安全与认证，证书文件缺失时不得生成假证书。
- A06：办公地点和联系方式，地址必须来自权威资料。
- A07：联系餐道 / 预约演示 CTA。

## 交互状态

- 默认：公司背景。
- Hover：时间点、服务支柱或城市显示短说明。
- Click：锁定年份或城市，内容区切换。
- Scroll：时间线进度随滚动变化。
- Mobile：时间线纵向，城市使用 Accordion。

## 素材

公司图片、办公室图片、认证文件需要真实素材。不要生成证书或地址。

## 参考图与素材文件

- 参考图编号：`ref-01-hero-atmosphere`、`ref-05-typography`、`ref-06-light-texture` 当前被首页母版缺失阻塞；不可用历史图替代。
- 真实素材文件：暂无公司照片、办公室照片、认证文件或城市地图素材。

## 不允许

不要使用“从经验长出”这类口语化或 AI 化表达；不要承诺未确认 SLA。
