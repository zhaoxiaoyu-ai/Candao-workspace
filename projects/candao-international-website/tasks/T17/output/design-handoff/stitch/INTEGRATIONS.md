# INTEGRATIONS Prompt

## 页面目标

验证餐道如何处理接入对象、数据流、权限和异常处理。不要做 Logo 墙。

## 访客可见内容

标题：先確認接入對象、資料方向與異常處理，再談整合。  
说明：整合能力頁以 Connector 為中心，說明外賣平台、自建入口、POS / KDS、CRM、支付、ERP、配送和 API 如何回到餐道營運鏈路。

## 模块顺序

1. I01 Connector Hero。
2. I02 八类系统交互网络。
3. I03 API Data Flow。
4. I04 POS / Store 与 Delivery 两类深度场景。
5. I05 接入评估 CTA。

## 模块呈现方式

- I01：Connector Hero，中心节点和外围对象以方向线进入。
- I02：八类系统交互网络，Hover 临时点亮，Click 锁定右侧详情。
- I03：API Data Flow，用 Menu、Order、User、Basic Info 数据包说明方向。
- I04：POS / Store 与 Delivery 两个深度场景，用 Tab 切换。
- I05：接入评估 Checklist + CTA，随当前接入对象预选。

## 交互状态

- 默认：外卖平台订单进入 OMS。
- Hover：点亮接入对象和数据方向。
- Click：锁定对象，显示字段、权限、异常和 CTA。
- Scroll：API 数据包依次进入 Connector。
- Mobile：网络图简化为核心节点和 Accordion。

## 素材

不使用合作方 Logo。API 和 Connector 图形可用矢量表达，不生成外部品牌标识。

## 参考图与素材文件

- 参考图编号：`ref-03-connector-section`、`ref-04-isometric-material`、`ref-05-typography` 当前被首页母版缺失阻塞；只用于方向记录，不作为可导入图片。
- 真实素材文件：无合作方 Logo 文件，且本页默认不使用外部 Logo。
- 可用内部素材：`motion-storyboards/integration-network/storyboard.md` 可作为接入网络动效说明。
- 图形表达：允许用矢量节点、连线、API 数据包、权限和异常标签表达 Connector，不得暗示已确认合作关系。

## 不允许

不要写“所有系统均可接入”“无缝集成”或未确认合作状态。
