# HOME Prompt

## 页面目标

建立餐道在餐饮与零售 O2O 营运中的行业专属性、规模可信和全链路能力印象，并导向 Platform、Customers 和 Demo。

## 访客可见内容

标题：把餐飲與零售 O2O 的訂單、門店、配送與數據接成一條營運鏈路。  
说明：餐道面向品牌總部和多門店營運，連接外賣平台、自有點餐入口、POS / KDS、CRM / 會員、配送資源、支付、ERP 和財務數據，讓訂單、餐單、履約、對賬與分析回到同一條可追溯鏈路。

## 模块顺序

1. H01 Hero：餐饮场景、产品截图舞台、Logo 带、双 CTA。
2. H02 Connector：中心营运中枢和六类连接对象。
3. H03 五项能力 Sticky Explorer。
4. H04 数字和品牌可信证明。
5. H05 重点客户案例入口。
6. H06 Final CTA。

## 模块呈现方式

- H01：电影感餐饮场景 Hero，右侧真实产品截图舞台，Logo 带放在 Hero 下方。
- H02：左侧短文案，右侧 3D / 矢量连接中枢。
- H03：桌面端 Sticky capability explorer，移动端改为 Accordion / 单列切换。
- H04：全宽数字证明带，不隐藏核心数值。
- H05：主案例入口，不展开成完整案例页。
- H06：深色转化区，主 CTA 到 Demo，次 CTA 到 Platform。

## 交互状态

- 默认：Hero 显示主截图位和「預約產品演示」「查看平台能力」。
- Hover：CTA 和截图外框增强。
- Click：主 CTA 到 Demo，次 CTA 到 Platform。
- Scroll：H02 节点依次点亮；H03 能力随滚动切换。
- Mobile：H03 改 Accordion，截图舞台改单张滑动。
