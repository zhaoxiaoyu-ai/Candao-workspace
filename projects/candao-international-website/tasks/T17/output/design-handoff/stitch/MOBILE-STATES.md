# Mobile States

移动端基准宽度：390px。

## 通用

- Header：Logo、Demo CTA、菜单按钮。
- 页面主内容宽度使用安全边距，不横向溢出。
- 不把所有桌面 Grid 直接压成单列，应按组件类型替换。

## 组件替代

- Sticky Explorer → Accordion。
- 产品截图舞台 → 单张截图滑动或缩略图切换。
- 系统网络 → 中心节点 + 核心对象 Accordion。
- 案例 Carousel → 单卡片轮播。
- 多步骤表单 → 单列 Stepper，实时摘要折叠。
- FAQ → Accordion。

## 禁止

- 移动端隐藏关键业务对象、状态、条件、数据口径或下一步。
- 为了塞入卡片而缩短产品名。
- 使用统一大写改变 `iDMS` 或 `SaaS`。
