# DEMO Prompt

## 页面目标

把预约演示从普通联系表单改为场景化分流：产品演示、销售、合作、支持查询。

## 访客可见内容

标题：預約餐道產品演示前，先告訴我們你的營運場景。  
说明：請留下品牌、地區、門店規模、目前使用的外賣平台、POS 和主要問題。我們會根據場景安排 OMS、DMS、iDMS、CDBI 或接入演示。

## 模块顺序

1. D01 Hero。
2. D02 联系意图选择。
3. D03 多步骤场景与系统表单。
4. D04 实时需求摘要。
5. D05 支持分流与隐私。
6. D06 提交成功状态。

## 模块呈现方式

- D01：高可信 Demo Hero，右侧实时需求摘要预览。
- D02：四项意图选择器，选中后字段和提示变化。
- D03：多步骤 Stepper，保留品牌、地区、门店规模、渠道、系统和主要问题。
- D04：右侧 Sticky 需求摘要，移动端折叠在当前步骤下方。
- D05：既有客户支援与新客 Demo 分流，隐私说明待正式确认。
- D06：提交成功状态，显示需求摘要、下一步和返回入口。

## 交互状态

- 默认：第一步选择联系意图。
- Hover：选项焦点边框和简短说明。
- Click：选择意图后字段和推荐模块同步变化。
- Submit：显示需求摘要、下一步和返回入口。
- Mobile：390px 单列 Stepper；摘要可折叠。
