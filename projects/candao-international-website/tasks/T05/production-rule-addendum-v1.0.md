# T05 Production Rule Addendum v1.0

本 Addendum 受 `projects/candao-international-website/tasks/Fix-00/output/Website Production Guideline v1.0.md` 约束。

本文件用于补充 T05 任务定义，并覆盖任何与其冲突的下游生成解释。

## Navigation Lock

T05 是官网 Sitemap 和导航层级的唯一事实来源。

有效一级导航：

- 首頁 Home
- 解決方案 Solutions
- 平台 Platform
- 整合能力 Integrations
- 客戶案例 Customers
- 關於 Candao About
- Contact / Demo

## 禁止变更

后续任何 Agent、Skill、Figma、Stitch、AI Web Generator、Prototype、Review 和实现任务都不得：

- 新增一级导航。
- 修改导航层级。
- 将产品能力页提升为一级导航。
- 将内部原型切换控件当成官网导航。

## 产品能力页归属

以下产品能力页必须保留在 Platform 下：

- Order Management
- Delivery Management
- Menu & Store Management
- First-party Ordering
- Data Intelligence

这些页面可以在内容模块中被重点展示，但不得成为一级导航。
