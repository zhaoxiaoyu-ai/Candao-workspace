## 0. v0.2 修订说明

v0.2 不是重新定义官网，而是在 v0.1 与 C v2 一级主页基础上补齐用户截图目录中的缺口。

主要修订：

| 修订点 | 说明 |
|---|---|
| 恢复 Resources | T05 已包含 `Resources` 一级结构，C v2 未生成对应主页。本版恢复为 `資源` 一级目录。 |
| 补齐餐饮零售场景 | 新增 `餐飲與零售`、`手機點餐`、`自助點餐`。 |
| 补齐配送链路 | 新增 `配送管理與騎手 App`、`配送調度`、`聚合物流管理`。 |
| 补齐 Integrations 命名 | 对齐 `外送平台`、`POS`、`CRM`、`第三方物流`、`支付閘道`。 |
| 补齐 Resources 内容 | 新增 `支援中心`、`常見問題`、`媒體與新聞`、`案例資源`、`了解更多`、`查詢表單`。 |
| 补齐 About 内容 | 新增 `關於我們`、`里程碑`、`加入我們`、`聯絡我們`。 |
| 保持能力层级 | `Order Management`、`Delivery Management`、`Riders App`、`Dispatch` 不进入一级导航。 |
