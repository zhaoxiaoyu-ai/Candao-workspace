## Prompt 方向摘要

### 1. 餐厅运营产品展示图

生成真实餐厅运营场景：现代餐厅柜台、POS 平板、订单屏、厨房出餐区域、暖色服务灯光和 `#528dff` 蓝色设备高光。限制为无品牌 Logo、无客户名、无可读文字、无未确认数字。

### 2. 平台控制台高保真 UI

生成企业级餐饮 SaaS 控制台：订单渠道、门店运营卡、配送状态、数据概览、总部可视化、图表、表格、告警行和产品卡。限制为无真实品牌、无可读英文、无客户名、无数字证明。

### 3. 配送调度地图 UI

生成配送管理控制台：地图、路线、骑手标记、订单队列、异常处理卡、工作流步骤和状态卡。限制为无真实地址、无客户名、无可读文字、无未确认事实。
