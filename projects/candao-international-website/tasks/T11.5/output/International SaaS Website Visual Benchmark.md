# International SaaS Website Visual Benchmark

任务：T11.5-A / Task A03  
日期：2026-08-05  
输出语言：简体中文  
参考来源：Aigens、Deliverect、TabSquare 官方网站，均为 2026-08-05 检索。

## 1. 基准结论

Candao 不应复制任何一个参考网站。正确方向是组合三类能力：

- Aigens 的餐饮科技行业可信感；
- Deliverect 的国际 SaaS 平台叙事和集成结构；
- TabSquare 的餐饮场景 + 数字体验叙事。

落到 Candao，应形成：

```text
真实餐饮营运摄影
+
结构化 SaaS UI Overlay
+
Capability Map
+
Purposeful Product Motion
```

## 2. Visual Benchmark Matrix

| 参考 | 借鉴能力 | 应用页面 | 禁止复制 |
| --- | --- | --- | --- |
| Aigens | 企业级 F&B 科技可信感；强调大规模餐饮营运场景与系统连接 | Home Hero、Trust Module、Restaurant Chains、About | 不复制客户 Logo、认证、SLA、数字；不把页面做成本地企业介绍或认证墙 |
| Deliverect | Omnichannel digital ordering、API-first、integration-led 的 SaaS 平台叙事 | Products / Platform、Integrations、Order Management | 不复制其品牌色、版式、文案和客户案例；不把 Candao 写成只做外卖聚合 |
| TabSquare | 餐饮场景、顾客旅程、数字点餐体验与视觉叙事结合 | Home Product Showcase、Digital Ordering 场景、Motion Storyboard | 不做过度营销式餐饮广告；不把首页变成消费者体验站 |

## 3. Hero 基准

| 维度 | 国际 SaaS 标准 | Candao 应用 |
| --- | --- | --- |
| 构图 | 首屏必须快速表达业务类别、受众和产品形态 | 左侧保留可读负空间，右侧展示餐饮高峰营运与 UI Overlay |
| 摄影 | 真实业务现场，不用抽象科技背景 | 餐厅前台、厨房、取餐、配送交接、门店协作 |
| UI Overlay | 产品界面解释价值，不装饰 | Order Queue、Store Status、Delivery、Data Return |
| Typography | H1 稳重清晰，支持 5 秒理解 | 繁體中文 H1 大字，正文短句，CTA 明确 |

## 4. Product Showcase 基准

| 维度 | 国际 SaaS 标准 | Candao 应用 |
| --- | --- | --- |
| UI 展示方式 | 产品界面与业务流程绑定 | 不做功能列表，改用 Order → Store → Delivery → Data 工作流 |
| 产品叙事 | 先解释业务结果，再展示能力 | “总部更可视、门店少切换、配送更可控” |
| 动效 | Motion 解释状态变化 | Scroll-triggered reveal、stepper、状态 chip 切换 |
| 可信边界 | 不用未确认数字硬撑 | Trust fallback 使用能力信任层 |

## 5. Layout 基准

| 维度 | 国际 SaaS 标准 | Candao 应用 |
| --- | --- | --- |
| 留白 | 首屏开放，核心 UI 区紧凑 | Hero 不进卡片；UI Demo 使用克制白色面板 |
| 信息密度 | SaaS 信息要密，但可扫描 | Product Showcase 与 Platform UI 使用 dashboard 结构 |
| Section 节奏 | Hero → Trust → Problem → Product → CTA | 本轮 Home Figma 已按该节奏生成 |
| 视觉层级 | 页面要有高潮，而不是均匀卡片 | Home Hero 与 Platform Capability Map 作为视觉峰值 |

## 6. Motion 基准

| 维度 | 国际 SaaS 标准 | Candao 应用 |
| --- | --- | --- |
| Scroll | 用滚动推进理解 | Platform UI Motion Storyboard 使用 4 个阶段 |
| Transition | 状态变化要平稳 | 300-500ms、ease-out、stagger 进入 |
| UI Animation | 数据变化服务业务 | 订单进入、队列统一、门店负载、总部汇总 |
| Mobile Downgrade | 移动端不强行复刻桌面复杂动效 | 静态 Hero 封面 + compact UI overlay + steps |
