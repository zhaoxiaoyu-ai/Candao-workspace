项目：餐道国际官网重构  
日期：2026-08-03  
输出语言：简体中文；Prompt 保留英文关键词。

## 1. 修正范围

本文件补充 T11.5 之后所有 Stitch、AI Web Generation、Figma-to-Web、Web Prototype 的生产语言规则。

不重新生成当前 Figma 原型。

## 2. Mandatory Prompt

所有网页生成 Prompt 必须包含：

```text
Generate a Traditional Chinese first international SaaS website.

Language:
Traditional Chinese.

Do not display bilingual content.

Include language switch:
繁中 / EN

Visual style:
Premium SaaS
Large Editorial Photography
Semi-real SaaS UI
Product Motion
```

## 3. Page Output Rule

默认生成：

```text
TC Production Version
```

Frame / Page 命名：

```text
Home / Desktop 1440 / TC
Platform / Desktop 1440 / TC
Order Management / Desktop 1440 / TC
Delivery Management / Desktop 1440 / TC
Contact / Desktop 1440 / TC
```

English 页面必须另行生成：

```text
Home / Desktop 1440 / EN
```

## 4. 禁止生成

禁止生成：

- 同屏繁體中文 + English Hero；
- 中文标题 + English CTA；
- English subtitle 作为装饰文案；
- 内部简体中文说明；
- 设计注释进入网页；
- Copy 文档式双语内容页。
