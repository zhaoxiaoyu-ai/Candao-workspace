# Candao 官网目录、页面文案与交互内容确认表 v0.1

## 0. 使用说明

本文用于先确认 Candao International Website 的目录、页面文案、交互前后文案与展示方式。

状态：待人工确认。

语言规则：

- 本文档说明使用简体中文。
- 官网展示文案默认使用繁體中文。
- English 仅作为 Locale 标签、页面路径、产品名、第三方名或技术术语保留。

结构规则：

- T05 Sitemap 为唯一 IA 来源。
- `Order Management` 与 `Delivery Management` 只能作为 `Platform` 下的产品能力页，不得提升为一级导航。
- `Resources` 暂不作为当前一级导航，可作为 Footer / Phase 2 内容承载 FAQ、Support、Guides。
