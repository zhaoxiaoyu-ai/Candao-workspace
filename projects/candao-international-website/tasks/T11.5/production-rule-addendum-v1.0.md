# T11.5 Production Rule Addendum v1.0

本 Addendum 受 `projects/candao-international-website/tasks/Fix-00/output/Website Production Guideline v1.0.md` 约束。

本文件用于补充 T11.5 任务定义，并覆盖任何与其冲突的下游生成解释。

## A/B/C 边界锁定

### A：Design Production

A 负责：

- 生产级 Figma 设计
- 可编辑 Design System
- 高保真执行
- UI 与视觉精修

A 不得重新定义 IA。

### B：Art Direction Review

B 负责：

- Creative Direction
- Visual Critique
- Benchmark Scoring
- 生成前和生成后的规则执行

B 不是页面生成器。

### C：Web Prototype Exploration

C 负责：

- 快速网页原型探索
- Stitch 或 AI Web Generator 测试
- 交互和版式探索

C 必须使用锁定 IA 和已确认视觉方向。

C 输出不自动等于参考案例或最终设计。

## AI Web Generator Lock

Stitch 和 AI Website Generator Prompt 必须由以下四层信息组成：

1. 来自 T10 或已确认 Creative Direction 的 Brand Direction。
2. 来自 T05 和 Website Production Guideline v1.0 的 Website Structure Lock。
3. 来自 T08/T09 的 Page Experience。
4. 来自 T10 和已确认视觉资产的 Visual Asset Direction。

生成器不得自由读取全部 Markdown 后重新解释导航。

`Order Management` 和 `Delivery Management` 不得提升为一级导航。

C 输出进入任何生产用途前，必须检查：

- IA Lock
- Locale Lock
- Visual Anchor
- Product Showcase Quality
- Interaction Intent
- International SaaS Quality
- Development Feasibility
