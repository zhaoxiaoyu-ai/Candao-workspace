## T47 不合格原因

1. 页面角色不够正式  
   `接入證據與資源` 更像内部整理名，不像一个可上线页面。T48 改为 `接入評估中心`。

2. 首页风格继承停留在颜色层  
   T47 借用了暗色、蓝色和卡片，但没有建立首页式的产品舞台、系统中枢、案例证明和 CTA 节奏。

3. 内容覆盖没有转化为页面组件  
   T47 的 `224/224` 说明内容没有丢，但没有说明哪些内容是首屏默认、哪些进入工作台、哪些进入资源路由或演示摘要。

4. 产品 UI 仍偏抽象  
   T47 的接入工作台以文字说明为主，缺少字段映射、同步状态、异常回传、推荐演示模块等半真实 UI。

5. Stitch 输入不适合首轮生成  
   T47 prompt 把 224 条内容覆盖和大量禁用项压给生成器，容易再次出现“看起来完整但不像高保真页面”的结果。

## T48 修正

- 首屏新增 `接入評估工作台`，直接展示系统来源、当前问题、AMS / Connector、OMS、Menu Center、DMS / iDMS、財務對賬、CDBI 和下一步。
- 深色系统段改为 `接口與資料流評估`，包含 left rail、搜索栏、字段表、状态 chips、资料对象和异常回传。
- 客户段改为案例证据板：实名案例卡、案例下一步、授权规模指标和多业态结果。
- 资源段改为任务路由：评估中、导入中、日常营运、技术查询，对应接入准备、营运 FAQ、案例资源、支援中心、媒体与公司资料、产品演示分流。
- 判断矩阵保留，但从审稿式表格改为页面内决策台。
- CTA 改为演示摘要，让前面的系统、案例和资源选择能够进入销售转化。
