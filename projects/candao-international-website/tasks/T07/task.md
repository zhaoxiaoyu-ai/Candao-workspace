# Task T07: 官网 Copy 优化与定稿

## Goal

基于 T06《Website Copy Document》进行官网 Copy 优化、收敛和定稿，输出国际官网最终可审核的页面文案。

T07 的任务不是重新生成更多页面内容，而是优化 T06：统一品牌语气、提升英文自然度、强化差异化表达、自然融入 SEO 关键词、优化 CTA，并控制页面长度。

## Output

《Final Website Copy V1.0》

## 前置输入

必须读取：

1. `tasks/T06/output/website-copy-document-2026-08-03.md`
2. `tasks/T06/output/t06-v1.1-copy-optimization-note-2026-08-03.md`
3. `tasks/T05/output/website-sitemap-2026-08-02.md`
4. `tasks/T03/output/candao-international-website-strategy-v1.0-2026-08-02.md`

优先依据：

- T06 v1.1 的 Copy Priority；
- T06 v1.1 的品牌差异化表达原则；
- T06 v1.1 的 Homepage Trust Module 备用方案；
- T06 v1.1 的 Product UI Demo 结构规范；
- T06 v1.1 的 SEO Keyword Mapping；
- T05 v1.1 的 P0 / P1 / 结构预留 / Phase 2 页面等级。

## 输出语言

全部使用繁体中文 + 英文。

## Requirements

- 每个页面、每个 Section、每个 CTA 都必须同时输出繁体中文和英文。
- 不要输出简体中文网页文案。
- 可保留 `Page`、`Section`、`Headline`、`Description`、`CTA` 等英文字段名。
- 繁体中文用于香港及亚洲市场审核，英文用于国际官网正式展示。
- 必须以 T06 为主输入进行优化，不重新设计 Sitemap，不新增主导航。
- 必须按 Copy Priority 控制深度：
  - 深度 Copy：Home、Solutions Overview、Platform Overview、Order Management、Delivery Management、Integrations Overview。
  - 中深度 Copy：Restaurant Chains、Contact / Book a Demo、Customers Overview。
  - 简化 Copy：Menu and Store Management、First-party Ordering、Data Intelligence、Multi-store Operations、Digital Ordering、FAQ、Support、About Us。
  - 谨慎占位：Security and Service Capability、Integration 分类页、Customer Story Template。
  - 方向保留：Phase 2 页面不输出完整正式 Copy。
- 必须强化差异化表达：不要只讲 `connect operations`，应表达复杂餐饮营运场景中的连接能力，例如 channels、stores、markets、delivery、integrations。
- 必须为 Home 准备无客户 Logo 授权时的 Trust Module 版本。
- 必须为重点产品页面保留 UI Demo 结构：Scene、Action、UI、Business Result。
- 必须自然融入 SEO Keyword Mapping，不得生硬堆砌关键词。
- 必须优化英文表达，避免直译腔。
- 必须优化 CTA，确保不同页面的 CTA 与商业目标一致。
- 必须进行页面长度控制，不得把 P1、结构预留或 Phase 2 页面写得比 P0 页面更重。
- 未确认客户 Logo、客户案例、规模数字、认证、SLA、集成状态、Pricing 和具体合作状态不得写成正式官网事实。

## Acceptance

- 页面 Copy 可进入 T08 UX Agent 与 T12 审核 Agent。
- 不存在只有单语版本的官网展示文案。
- 不存在简体中文官网正式展示文案。
- 输出为可审核的 `Final Website Copy V1.0`。
- Copy 已完成双语润色、品牌语气统一、SEO 优化、CTA 优化和页面长度优化。
- 结构预留与 Phase 2 页面没有被扩写成完整正式页面。
- 不存在未确认资料被写成公开事实。
