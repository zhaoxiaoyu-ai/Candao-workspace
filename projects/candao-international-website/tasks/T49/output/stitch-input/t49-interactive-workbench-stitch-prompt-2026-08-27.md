# T49 Stitch 输入提示词：接入評估中心互動工作台

## 目标

生成 `接入評估中心 / Desktop 1440 / TC` 高保真页面。页面不是长文说明页，而是一个前端可实现的互动评估工作台。

## 页面气质

继承已确认首页风格：暗色餐饮运营 Hero、真实业务场景图、企业级产品工作台、克制蓝色连接线、白底案例证据、深色授权数据带、清晰销售转化 CTA。

## 首屏

- 顶部导航：首頁、解決方案、平台、整合能力、客戶案例、資源、關於餐道、繁中 / EN、預約產品演示。
- H1：以前端工作台方式查看接入、案例與資源。
- 副文案：選擇目前卡住的營運問題，頁面會同步切換系統來源、資料流、相似案例、資源入口與產品演示摘要。
- 首屏下方放一个深色产品工作台预览，左侧是问题按钮，中央是 AMS / Connector 系统连接图，右侧是演示摘要。

## 主体交互

用同一个工作台承载以下状态：

- 问题选择：漏單與接單超時、餐單同步、配送超時、對賬差異、多品牌門店。
- 步骤导览：選擇問題、核對系統、查看案例、匹配資源、形成演示摘要。
- 系统拓扑：外賣平台、自建點餐、POS / KDS、CRM / 會員、支付 / ERP、配送 API 进入 AMS / Connector，再回到 OMS、Menu Center、DMS / iDMS、財務對賬、CDBI。
- 状态表：資料對象、來源、狀態、下一步操作。
- 右侧摘要：目前問題、接入或產品關係、相似案例、資源下一步、建議演示模組。

## 案例与资源区

同一个场景下切换四个 Tab：

- 案例：显示 Pizza-Box、JIA Group、Jardine Group 及多业态案例索引。
- 資源：显示接入準備清單、營運 FAQ、案例資源。
- 支援：显示支援中心查询入口和异常问题摘要。
- 演示：显示产品演示分流，按问题匹配 OMS、Menu Center、DMS / iDMS、財務對賬或 CDBI。

## 数据带

保留独立深色授权规模数据带，只展示已确认指标：5000+、500M+、400+、200K+、4.5B+、30%。

## CTA

页面末端是演示摘要表单预览，字段包括：需要處理的問題、已使用系統、建議演示模組、推薦資源。主按钮为 `預約產品演示`。

## 生产约束

- 页面可见文本使用繁體中文单一 Locale。
- 中文 / 繁體中文品牌显示使用「餐道」。
- 不显示 `Finance Center`，繁體中文使用「財務對賬」或「平台訂單與 OMS 訂單對賬」。
- 保持 `iDMS`、`SaaS`、`AMS / Connector`、`Menu Center`、`CDBI` 的大小写。
- 不显示 Material icon ligature、假备案、未确认 SLA、未确认合作状态或未确认客户 Logo。
