## 3. Visual Prototype Language Rule

默认视觉探索必须模拟：

```text
繁體中文真实官网页面
```

必须使用：

- 繁體中文 Navigation；
- 繁體中文 Headline；
- 繁體中文 Body Copy；
- 繁體中文 CTA；
- 繁體中文 UI Label。

可保留的英文仅限：

- 品牌名 `Candao`；
- 专有产品或技术名；
- 页面 / Frame / Component 命名；
- 必要的设计关键词。

## 4. Design Review Checklist 增补

### Language Check

检查：

- 是否只有一个语言版本；
- 是否默认繁體中文；
- 是否符合真实官网状态；
- 是否预留语言切换；
- 是否没有双语 Hero；
- 是否没有内部说明进入页面；
- English 是否作为独立 Locale，而不是辅助字幕。
