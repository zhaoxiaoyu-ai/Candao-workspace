## Visual Production Lock

T10 视觉方向必须成为生产约束，而不只是情绪描述。

禁止的视觉模式：

- 普通企业官网布局
- 产品说明书式结构
- 重复卡片堆叠
- 软件截图墙
- 泛 AI 科技背景
- 3D 科技球体
- 粒子特效
- 纯结构图式页面

Hero 必须包含：

```text
Large Editorial Photography
+
Semi-real SaaS UI
+
Clear CTA
```

Product Showcase 必须表达：

```text
Workflow
-> UI State Change
-> Business Outcome
```

Reference Selection、Moodboard Direction、Hero Direction 和 UI Style 在进入生产前必须人工确认。
