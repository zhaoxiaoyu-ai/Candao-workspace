# Task T10: 视觉设计 Agent

## Goal

运行视觉设计 Agent，基于 T03 Strategy、T07 Final Copy、T08 UX Specification 和 T09 Prototype Validation 提出国际官网视觉方向。

T10 不重新解释官网策略，不重写 Copy，不重新做 UX，不重新探索网站方向。T10 的重点是将已确认的品牌策略、页面内容、UX 和原型验证转化为 Visual Direction、UI Style、Motion Style 和 Design System。

## Output

《Website Visual Direction》

## 输出语言

简体中文；设计关键词保留英文。

## Example Format

```markdown
视觉方向：

International SaaS Style

Large Editorial Photography

Product UI Motion

Minimal Interface
```

## Requirements

- 必须读取：
  - `tasks/T03/output/candao-international-website-strategy-v1.0-2026-08-02.md`
  - `tasks/T07/output/final-website-copy-v1.0-2026-08-03.md`
  - `tasks/T08/output/website-ux-specification-2026-08-03.md`
  - `tasks/T08/output/t08-v1.1-design-execution-supplement-note-2026-08-03.md`
  - `tasks/T09/output/website-prototype-validation-*.md`
- 必须继承 T09 v1.1 的：
  - Prototype Acceptance Criteria；
  - Prototype Fidelity Level；
  - Interaction Complexity Level；
  - Visual Mood Input。
- 输出品牌视觉方向、页面情绪、版式策略、图像策略、动效方向、UI 展示方式和设计系统建议。
- 必须包含：
  - Visual Concept；
  - Visual Direction；
  - Typography；
  - Color System；
  - UI Style；
  - Motion Style；
  - Design System；
  - Photography & Media Direction；
  - Page Visual Priority；
  - Moodboard Direction；
  - Figma Execution Notes。
- 设计关键词可使用英文，以便后续设计师和外部参考统一。
- 说明部分使用简体中文。
- 必须按 T08 的 Visual Priority 分配视觉投入，不得为所有页面平均设计。
- 必须按 T09 的 Prototype Fidelity Level 控制高保真范围，不得把所有页面直接推进完整 High-fi。
- 必须按 T09 的 Interaction Complexity Level 控制 Motion 成本，L4 Product Simulation 不作为默认范围。
- Home、Products / Platform、Order Management、Delivery Management 是视觉和 Motion 重点。
- Cases、Company、FAQ、Support 以模板化和基础信息设计为主。
- 不使用普通办公室、商务握手、泛科技、抽象 AI 或未授权客户素材作为主视觉方向。

## Output Structure

必须按以下结构输出：

1. `Visual Concept`
   - 定义 Candao 国际官网视觉总概念。
   - 不重新定义官网定位，只视觉化 T03 冻结战略。
2. `Typography`
   - Headline style；
   - Body style；
   - SaaS UI label style。
3. `Color System`
   - Primary；
   - Accent；
   - Neutral；
   - Status / Data colors。
4. `Photography Direction`
   - Home Hero；
   - Product / UI context；
   - People and operations；
   - 禁用素材类型。
5. `UI Style`
   - Dashboard；
   - Cards；
   - Data Flow；
   - Capability Map；
   - Form。
6. `Motion Style`
   - Scroll；
   - Transition；
   - UI Animation；
   - Mobile downgrade。
7. `Design System`
   - Token categories；
   - Components；
   - States；
   - Responsive rules。
8. `Page Visual Priority`
   - Home；
   - Products / Platform；
   - Order Management；
   - Delivery Management；
   - Integrations Overview；
   - Contact / Book a Demo；
   - Template pages。
9. `Figma Execution Notes`
   - Frame structure；
   - Component naming；
   - Motion storyboard；
   - Handoff notes。

## Acceptance

- 文档能支撑 T11 视觉方案。
- 英文关键词清晰、可检索、可转化为设计参考。
- 文档能直接继承 T09 原型验证，不重新推翻页面节奏和交互范围。
