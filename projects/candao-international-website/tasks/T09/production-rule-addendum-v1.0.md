## Prototype Production Rule

T09 原型必须模拟真实官网行为，同时保留 IA 和 Locale 规则。

必要约束：

- 默认原型输出代表繁體中文真实上线页面状态。
- 内部原型控制可以用于切换页面、视口或模式，但必须被理解为内部控制。
- 内部原型控制不得被解释成正式官网导航。
- Product Showcase 交互必须表达 `Workflow -> UI State Change -> Business Outcome`。
- 原型输出在通过 IA、Locale、视觉、交互和可开发性检查前，不得作为参考案例。
