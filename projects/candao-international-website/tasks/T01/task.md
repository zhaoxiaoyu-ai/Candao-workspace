## 项目输出语言规范

本项目所有输出分为三个层级：

### 1. 内部策略及执行文档

用途：

项目分析、设计规划、Agent 执行说明。

语言：

简体中文。

包括：

- 官网策略分析；
- 用户分析；
- 信息架构；
- UX 规划；
- 视觉设计说明；
- Agent 规则。

### 2. 官网实际展示内容

用途：

最终用于国际官网页面。

语言：

繁体中文 + 英文。

规则：

每一个官网页面文案需要同时输出：

繁体中文版本：

用于香港及亚洲市场审核。

英文版本：

用于国际官网正式展示。

格式：

```markdown
繁體中文：

標題：

說明：

CTA：

English:

Headline:

Description:

CTA:
```

### 3. 页面设计及开发参考内容

用途：

设计师、开发人员执行。

语言：

简体中文为主。

涉及官网字段、页面标题、组件名称时保留英文。

例如：

```markdown
模块：
产品展示 Product Showcase

交互：
Scroll Animation
```
