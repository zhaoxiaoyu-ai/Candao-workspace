# T23 - 低保真逐页文案业务 QA 与收紧

## Status

done

## Goal

逐页复核 `T17` 低保真原型 8 个页面，确认此前约束的餐道业务专属性、行业术语、品牌显示、文案紧凑度和原型阶段不得擅自删减规则是否已经落地；发现问题后直接修正，并通过 `domain-copy` QA、截图和报告留痕。

## Scope

- 审查页面：首頁、解決方案、平台、整合能力、客戶案例、資源、關於餐道、預約產品演示。
- 审查来源：项目 `domain-copy/`、T15 旧官网 / PPT 证据矩阵、T22 最新补齐报告、当前低保真 HTML。
- 修正范围：低保真原型内可见文案、术语、页面任务表达、跨页重复和过长段落。
- 不进入：高保真 Figma、Stitch、React 前端、English 内容库、最终上线文案锁定。

## Acceptance Criteria

- 8 页均完成逐页审查并有页面级结论。
- 修正后的文案不使用无来源泛化价值表达替代业务事实。
- 中文 / 繁體中文语境默认使用「餐道」，仅在允许场景保留 `Candao`。
- 关键业务对象、状态、条件、数据口径和下一步操作不因精简被删除。
- `domain-copy` QA 通过。
- Google Chrome + Playwright 完成 8 页截图与导航验证。
- 输出审查报告、QA 输入、QA 结果，并更新项目状态文件。
