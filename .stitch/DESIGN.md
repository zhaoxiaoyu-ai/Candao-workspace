# Candao International Website Design System

## Product Positioning

Candao international website is a Traditional Chinese first B2B SaaS website for complex restaurant operations.

The site should communicate:

- Operational clarity for global restaurant SaaS.
- Real restaurant operations, not generic technology.
- Structured SaaS interface, not a dense product manual.
- Purposeful product motion for understanding order, store, delivery, data and system connection workflows.
- Trustworthy, practical, polished international B2B presence.

## Locale Rule

Primary visual production locale:

```text
Traditional Chinese
```

Visible website copy must use Traditional Chinese only.

Allowed English in visible screens:

- Candao brand name.
- Language switch label: 繁中 / EN.

Do not show bilingual body content, English subtitles, English CTA, internal simplified Chinese notes, unconfirmed client logos, real customer data, certifications, SLA, pricing or real integration status.

## Visual Direction

Design concept:

```text
Operational Clarity for Global Restaurant SaaS
```

Visual formula:

```text
Real Restaurant Operations
+
Structured SaaS Interface
+
Purposeful Product Motion
+
Global B2B Trust
```

The website should feel sophisticated, polished, trustworthy, practical and international. It should not look like a local software brochure, a generic AI startup page, a decorative landing page, or an internal system manual.

## Color System

Use a light, blue-led operational SaaS palette:

- Primary SaaS blue `#528dff` for primary CTAs, navigation emphasis, important product links and key platform connection states.
- Operational teal or green for success, healthy store status and connected system states.
- Service amber for restaurant peak pressure, delivery emphasis and warning states.
- System blue for data flow, information states and system connection.
- Controlled red for exceptions only.
- Deep ink neutral for headings, navigation and dark product UI panels.
- Cloud neutral for page background and quiet surfaces.
- Mist line for dividers, borders and flow lines.

Avoid a one-note blue page. Use neutral space as the base, with `#528dff` as the brand signal, teal/green for operational health, amber for service pressure and red only for exceptions.

## Typography

Use clear sans-serif typography that supports Traditional Chinese.

Hierarchy:

- Display: large, confident, readable hero statements.
- H1 and H2: clear page and section roles.
- Body: legible, restrained, enough line height for Traditional Chinese.
- Label: compact but never squeezed for UI chips, navigation and dashboard labels.

Do not use negative letter spacing for Traditional Chinese body text. Do not use decorative or futuristic type.

## Layout

Use a desktop-first 12-column grid for 1440px web screens.

Patterns:

- Sticky navigation bar with logo, Traditional Chinese nav items, primary CTA and language switch.
- Full-width hero section with high-impact restaurant operations photography and readable negative space.
- Semi-real SaaS UI overlay for operational status, order queue, delivery timeline and headquarters visibility.
- Structured product sections with capability maps, flow diagrams, UI demos and card grids.
- Full-width CTA band, not a nested card.

Do not use card-in-card layouts. Do not place hero content in a floating card. Keep page sections as bands or unframed layouts.

## Shape And Elevation

Use precise, modest shape language:

- Standard cards and containers: slightly softened to gently rounded corners.
- Product UI panels: crisp SaaS surfaces with subtle outlines.
- Buttons: clear and compact, not oversized or pill-like by default.
- Shadows: whisper-soft elevation only.

Cards should not become overly rounded consumer-style tiles.

## Photography And Media

Use large editorial restaurant operations photography:

- Peak-hour restaurant workflow.
- Front counter order intake.
- Kitchen preparation.
- Store team coordination.
- Delivery handoff.

People should be working naturally, not posing. Photography must show operation actions, not just food, ambience, office meetings or business handshakes.

## Product UI

Use semi-real SaaS UI rather than real product screenshots.

Core UI patterns:

- Unified order queue.
- Store status panel.
- Delivery timeline.
- Headquarters summary dashboard.
- Capability map.
- System connection lines.
- Exception panel.
- Status chips.
- Step indicators.

All data must be anonymized and fictional. Do not show real customer names, order numbers, maps, addresses, prices or platform logos.

## Motion

Motion principle:

```text
Purposeful Motion for Operational Understanding
```

Motion should only:

- Explain workflow.
- Show status changes.
- Guide next action.

Use slow reveal, stepper transition and subtle connection line movement. Avoid decorative motion, particles, complex route simulation, 3D objects or AI effects.

Desktop interactions may use guided UI demo patterns. Mobile should degrade to swipeable or stacked step cards. Reduced motion must have static equivalent states.

## Core Screens

### Home

Focus:

- Hero with restaurant operations photography.
- Semi-real SaaS UI overlay.
- Trust capability layer.
- Problem switcher.
- Product showcase capability flow.
- Clear demo conversion.

### Platform

Focus:

- Capability map as visual center.
- Candao platform node connected to order channels, POS, payment, loyalty, stores, delivery, data and headquarters visibility.
- Platform UI demo.
- Product entry cards.

### Order Management

Focus:

- Multi-channel orders entering a unified queue.
- Status timeline.
- Store execution and headquarters summary.
- Four-step workflow.

### Delivery Management

Focus:

- Peak delivery demand.
- Fulfillment option selection.
- Delivery tracking.
- Exception return to operations view.
- Four-step workflow.

## Accessibility And QA

Every screen must pass:

- Traditional Chinese single-locale visible copy.
- Language switch present in header.
- Primary CTA visible in hero and final CTA.
- Product UI explains operational value.
- No unconfirmed facts.
- No decorative generic tech background.
- Mobile layout can stack cleanly.
- Text remains readable and does not overlap UI panels.
